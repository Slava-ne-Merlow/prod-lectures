# Веб-презентация · Лекция 1

Откройте `dist/index.html` в браузере либо запустите статический сервер, указав `dist` как корень. Зависимости и интернет не нужны.

Десять слайдов: заглавный, устройство приложения, контракт фронтенда и бэкенда, HTTP-запрос, методы HTTP, HTTP-ответ, статусы, обработка запроса, первый endpoint на FastAPI и переход к лайвкодингу Books App. Теория использует примеры с пользователями; Books App появляется в конце.

Управление: ← / →, Page Up / Page Down, пробел — следующий слайд; Home / End; F — полный экран. Номера снизу кликабельны, ссылки `#1`–`#8` открывают нужный слайд. Стрелки работают и после клика по номеру. Видимых кнопок стрелок и полного экрана, а также таймингов нет.

Для записи: 1920×1080, полный экран. На небольших экранах блоки становятся вертикальными. Печать выводит все слайды. Время в сценарии ориентировочное — проверить на репетиции.

Визуальный источник: https://prodcontest.com/ — логотип, тёмно-зелёный #00402e, жёлтый #ffdd2d и светло-зелёный #b2c6c0. Схемы и композиция сделаны для лекции. Если Inter не установлен, используется Arial.

Сценарии находятся на уровень выше. Текущая версия предназначена для локального показа.

Проверка терминов для речи: [REST](https://developer.mozilla.org/en-US/docs/Glossary/REST), [методы HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Methods).

## Запись в OBS и текст ведущего

Запуск из папки `лекция 1/presentation`:

```bash
python3 presenter.py
```

- Источник «Браузер» в OBS: `http://127.0.0.1:8767/?obs=1`, размер 1920×1080.
- Пульт с текстом: `http://127.0.0.1:8767/speaker.html`. Кнопки и стрелки влево/вправо переключают слайд в OBS. Размер текста регулируется ползунком.
- Текст берётся из `books_app_video_1_part_1_theses_v2.md`, блоки разделяются `-----`. После изменения файла обновить пульт.
- Для записи с заметками использовать сцену «Презентация — слайды и камера». Она показывает только страницу слайдов и камеру. При захвате всего экрана заметки могут попасть в запись.
- Сервер должен работать всё время записи. Для лайвкодинга переключиться на сцену захвата нужного окна или экрана; заметки убрать с захватываемой области.

В локальной конфигурации OBS выбран выход 1920×1080, 30 кадров/с, качество записи HQ и контейнер MKV. Качество оценивать по короткой записи при масштабе 100%, а не по уменьшенному предпросмотру. При необходимости MKV можно преобразовать в MP4 через «Файл → Ремультиплексировать записи» в OBS.
