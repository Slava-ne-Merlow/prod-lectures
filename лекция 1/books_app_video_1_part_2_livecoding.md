# Лайвкодинг: два endpoint на FastAPI

Порядок: новый проект → установка → GET / → запуск → проверка в Swagger → GET /books → повторная проверка → завершение.

Действия выделены курсивом. Обычные абзацы — короткий текст для озвучивания. На записи используем файл `main.py`; готовый пример в репозитории — `livecoding.py`.

## 1. Создаём проект в PyCharm

*Создать обычный Python-проект Books App с новым виртуальным окружением .venv. Открыть встроенный Terminal в папке проекта. Убедиться, что терминал использует окружение проекта.*

Создадим проект для нашего каталога книг. Используем отдельное виртуальное окружение: в него установим зависимости этого проекта.

## 2. Устанавливаем FastAPI

*В терминале выполнить:*

```bash
python -m pip install "fastapi[standard]"
```

Установим FastAPI со стандартными зависимостями. Вместе с ним установятся инструменты для запуска сервера.

*Дождаться завершения установки. Кавычки вокруг fastapi[standard] нужны, в частности, для терминала zsh на macOS.*

## 3. Создаём main.py с первой ручкой

*В корне проекта создать `main.py`. Набрать код по частям:*

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def hello():
    return {"message": "Hello World"}
```

Импортируем FastAPI и создаём приложение app.

Декоратор app.get связывает метод GET и путь слеш с функцией hello. При таком запросе FastAPI вызовет эту функцию.

Функция возвращает словарь с приветствием. FastAPI преобразует его в JSON и отправит клиенту.

## 4. Запускаем сервер

*Сохранить файл. В терминале из папки с `main.py` выполнить:*

```bash
fastapi dev main.py
```

Запускаем сервер. Режим dev автоматически перезапускает приложение, когда мы сохраняем изменения в коде.

*Дождаться сообщения `Application startup complete`. Оставить терминал работающим.*

## 5. Проверяем первую ручку в Swagger

*Открыть `http://127.0.0.1:8000/docs`. Раскрыть GET / → Try it out → Execute.*

По пути /docs FastAPI предоставляет Swagger UI. Здесь можно посмотреть доступные запросы и сразу выполнить их.

Выбираем GET по корневому пути и отправляем запрос. Swagger выступает клиентом и обращается к нашему серверу.

В ответе видим статус 200 и JSON с сообщением Hello World. Первая ручка работает.

## 6. Добавляем список книг

*Вернуться в `main.py`. Ниже первой функции, на том же уровне отступов, добавить:*

```python
@app.get("/books")
def get_books():
    return []
```

Добавим GET /books для получения списка книг. Пока функция возвращает пустой список: хранение и добавление книг мы ещё не реализовали.

*Сохранить файл. Дождаться перезапуска сервера. Обновить страницу /docs, чтобы появилась новая ручка. Раскрыть GET /books → Try it out → Execute.*

После обновления документации появилась вторая ручка. Отправляем запрос и получаем статус 200 и пустой список.

Это успешный ответ: запрос обработан, просто книг пока нет. У нас один сервер и два обработчика для разных путей.

## 7. Завершаем

*Показать весь `main.py`.*

Мы создали приложение FastAPI, запустили сервер и проверили две ручки через Swagger. Одна возвращает приветствие, другая — список книг.

В следующем уроке добавим книги и получение отдельной книги по идентификатору. Спасибо за просмотр, до встречи!

*После записи остановить сервер в терминале: Ctrl+C.*

## Если команда запуска не работает

Обычная установка `pip install fastapi` не устанавливает весь набор инструментов для команды `fastapi dev`. В текущем окружении проекта отсутствовал пакет `fastapi-cli`. Доустановить стандартные зависимости можно той же командой:

```bash
python -m pip install "fastapi[standard]"
```

Установка и запуск должны выполняться в одном виртуальном окружении. Если терминал PyCharm его не активировал, на macOS/Linux из корня проекта выполнить:

```bash
source .venv/bin/activate
```

После этого повторить установку и запуск. Для проверки выбранного интерпретатора:

```bash
python -c "import sys; print(sys.executable)"
```

Путь должен вести в окружение проекта. Если оно называется иначе, использовать его имя вместо `.venv`.

Альтернативный запуск через Uvicorn, без команды `fastapi`:

```bash
python -m pip install fastapi "uvicorn[standard]"
python -m uvicorn main:app --reload
```

Здесь `main` — имя файла без `.py`, `app` — объект приложения. Выбрать один способ запуска, одновременно запускать оба не нужно.

Если порт 8000 занят, можно запустить `fastapi dev main.py --port 8001` и открыть `http://127.0.0.1:8001/docs`.

Команды сверены с [документацией FastAPI CLI](https://fastapi.tiangolo.com/fastapi-cli/). Проверка через Swagger описана в [первых шагах FastAPI](https://fastapi.tiangolo.com/tutorial/first-steps/).
