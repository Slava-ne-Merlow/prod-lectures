# PROD · Лекции по бэкенду

## Лекция 1. Клиент, сервер и первый endpoint

Материалы находятся в [лекция 1](<лекция 1/>): презентация, план и отдельные тексты для теории и лайвкодинга.

Открыть презентацию: `лекция 1/presentation/dist/index.html`. Она работает без установки зависимостей. Для запуска через localhost из корня репозитория:

```bash
python3 -m http.server 8080 --directory "лекция 1/presentation/dist"
```

Затем открыть http://localhost:8080. Переключение слайдов — стрелки на клавиатуре, полный экран — F.
